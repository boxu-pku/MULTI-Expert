# 陷阱：m2d-core-9.1 离轴网格（不贴 y=0 轴）在 hydro+transport 下卡死

**日期**：2026-11-13  **场景**：MULTI-2D.2026.3 的 M20_Step 体系

## 症状

网格不贴对称轴（y 从 r0>0 起，比如大半径近似平面几何）时：
- **纯 transport**（无 control.hydro 块）：正常 ✅
- **纯 hydro**：正常 ✅
- **hydro+transport 组合**：第一步 M20_Step 卡死（100% CPU、无输出、无进展）❌

贴轴（y=0 在域内）时同配置正常。

## 已排除

- 网格拓扑（三角形 CCW/边共享/退化全检过，完美）
- 材料（CH/Diamond/Al 表格 EOS、固定 λ）、Tmaxvar 值、external 浴、
  entry 名、ntemp、reflex——逐项二分均无关
- 网格规模（14×6 离轴也死）与 cell 宽高比

## 结论与规避

- M19_Radia 的 C 实现（拓扑排序/Sn 扫描）对离轴网格有隐含假设（可能与轴墙
  面积为零的处理有关），与流体的组合触发死循环；**未做 C 层修复**。
- **规避**：网格贴轴（y∈[0, ...]）；圆柱靶物理上 R=0 是对称轴，天然满足。
- 大半径"准平面"路线（r0=1cm）在 M20 体系不可用；需要平面几何+辐射时
  考虑 m2d-5.1 体系（XG151 配方）或其它方案。

## 调试方法备忘

- stdout 全缓冲：被 kill 时输出全丢——诊断用 `stdbuf -oL` 行缓冲。
- p()/encode()：r94 的 encode 只支持单 %g 参数；p(数值) 可打印。
- 快照二进制格式：`<t>`=4B 头+float32 记录，`<t>.d`=MF01 文本字段表；
  网格连接 pt/ct 只在 t=0 快照，场数据在每个快照（Lagrangian 网格移动）。
