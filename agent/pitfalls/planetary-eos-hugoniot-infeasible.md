# 行星 EOS 表 in-code Hugoniot 算例不可行：窄压缩段 + 低密度 RT→RE 病态

**日期**：2026-08-14
**状态**：已确认（AQUA 水表案例，用户定版改走表级 Hugoniot 三方对比）

## 症状

AQUA 水 EOS（T≤8.6 eV、ρ≤100 g/cc 的行星 EOS）1D Hugoniot 算例，用标准
厚平板 + 恒定辐射浴构型（make_hugoniot_cases.py）：
- T2/5/7/8 全档 dt 塌缩到 ~1e-16，时间步 100k 步仍爬行在 <1 ns
  （T2 是 nexit 耗尽"正常"退出而非跑通，实为死机式爬行）
- 密度剖面显示全域（含左边界）膨胀到低密度气体区（ρ~0.005 g/cc）

## 根因链（两条独立约束叠加，缺一不可）

1. **可用 Hugoniot 段极窄**：行星 EOS 的波后 T 随压缩比极陡。AQUA 表级反解
   显示波后 T≤8.6 eV 要求 ρ1≤2.46（该点 T=1.09 eV、P=6 Mbar、Us=14.9 km/s）；
   ρ1 一旦 >2.46，表级反解 T 突跳到 12.79 eV（源相变 + RT→RE 反演非单调），
   越出表上限。→ 只能 trad≤1–2 eV 的极弱驱动。
2. **弱驱动的辐射前驱穿透膨胀**：trad≤2 eV 时辐射前驱穿过整个 slab，
   全域（含左边界）稀疏膨胀到低密度气体区；而电子表低密度段（ρ≲0.1 g/cc）
   的 RT→RE 反演 dT/dE 病态（de 网格前几点近似退化、dT/dE~1e5 eV/de 单位，
   AQUA 源 100 K 冷点与第一温度点的能量间隔被压到同一 ΔE 格），
   → 温度导数异常 → 时间步控制 dt 塌缩。

## 排除的替代方案（均无效/不可用）

| 方案 | 结果 |
|---|---|
| tempmin 补丁（0.0000861→0.02） | 无效（病态在膨胀区 dT/dE，非 T 下限） |
| te0=1 eV 高温初态 | 跑完但无冲击波（全域预热吞没压缩） |
| ileft=1 反射左边界 | 无效（右驱动前驱仍穿全 slab） |
| 激光直接驱动（pulse_maxwell） | 可绕过前驱，但弱激光产生衰减波、非准定常，偏离标准 Hugoniot 方法论，未采用 |

## 处置（用户 2026-08-14 定版）

**表级 Hugoniot 三方对比**取代 in-code 冲击算例：`compute_table_hugoniot.py`
由入库表反解主 Hugoniot（自洽参考，验证表插值与冲击物理实现一致性），
与 AQUA/FEOS/Multi_BACK 三源经同一 RH 求解器的参考线叠加出图
（熔石英等无外部理论线材料的标准先例）。能量守恒由 wcheck_T5（全区加热）承担。

## 何时要想到它

任何 **T 上限 ≤ 几十 eV 的低温/行星 EOS**（AQUA、ICE、EOS 表 T 上限受限的
DFT 表等）要做 in-code Hugoniot：先查表级反解的 T(ρ1) 曲线，若可用压缩段
（波后 T 在表内）窄到驱动强度只能落进"辐射前驱穿透 + 膨胀病态"区，
则 in-code 冲击算例物理上不可行，直接走表级 Hugoniot + 加热算例双轨验证。
与 SiO2wk12（表 T 上限 10 eV，Hugoniot 校验同样不可用）同类。
