# Cliquid 表晚期张力振荡与单帧激波振铃：峰值提取判别法（滚动中位数）

**日期**：2026-09-04（`cases/HOPG_simulation/hopg_lif_scan/` E100 三例触发）
**材料**：Cliquid（hyades 液碳表，id 6000304/5），ρ0=2.2 直接激光驱动、无 CH 烧蚀层

## 1. 症状

弱驱动（100 J/⌀1.5 mm，I≈2.8×10¹¹ W/cm²）下三种数值事件，全部会污染
"层内峰值压强"这类 max 类统计：

| 事件 | 表现 | 本质 |
|---|---|---|
| 晚期张力振荡 | t≳32 ns 单帧/单胞正压强尖峰（+67、+81 GPa），邻胞全是 −5~−12 GPa，密度 1.54 紧邻 2.43 | 稀疏波把细胞带回冷曲线张力平台（ρ0=2.2 处 **−0.348 Mbar**）附近，塌缩-反弹 |
| tridia 崩溃 | 48.4 ns `singular matrix`，E100 三例齐崩 | 同上病灶的终极形态；**inegpre=0 对照同样晚期崩**（inegpre=1 只救早期单调性，救不了晚期张力区） |
| 单帧激波振铃 | 平台 65-67 GPa 上一帧 84（E200）；30-35 上一帧 50（E100） | 阵面穿过网格的瞬态振铃，0.1 ns 采样混叠；**不是晚期病，各能量级都有** |

## 2. 判别法（可复用）

1. **持续峰值**：对 P_layer(t) 做 5 帧（0.5 ns @dt_bout=0.1 ns）滚动中位数再取 max。
   物理激波压强是 ns 级平台，必然存活；单帧毛刺自动消失。单帧 0.1 ns 事件
   对物质压缩无贡献，判 "<X GPa" 类门槛应用持续值。
2. **晚期窗截断**：弱驱动组统计窗截 t≤40 ns（比崩溃早、比一切相关物理晚）。
   判据：看 min PT 是否长时间贴 −34.7 GPa 平台 + 尖峰邻胞符号。
3. **texit 截断**：E100 组 texit 6e-8→4.6e-8 换取 normal termination + 完整
   能量审计（9/9 全绿，误差 ≤2×10⁻¹³）；比保留崩溃尾巴干净。
4. **界面初值陷阱**：安静启动下 C 内部冻结在冷张力，HOPG/Al 界面初始读数
   ≈ −17 GPa =（−34.7+0）/2；激波到达后才是物理值，勿当异常。

## 3. 网格侧修复（2026-09-04 hopg_lif_scan 变体验证）

单帧阵面振铃的根治法：**无突变渐变网格**——C 层用单块 zonpar=1.02 几何渐变
（前脸 0.02 um→0.5 um）+ 均匀 0.5 块 + Al 0.5，全程无分辨率跳变：
- 基线（5 um 处 10 倍跳变）激波跨块界单帧尖峰 +27%，渐变网格后 **+1.3%**（消除）
- 前脸逐帧交替 12%→5.7%（dx 0.05→0.01 单调收敛，残余为物理瞬态）
- 界面峰值对网格不敏感（±2%），渐变网格不改变结论
hopg_lif_scan/gen_fine_variants.py 可复用（渐变块参数由 dx0 自动算出）。

## 4. 关联事实

- PT 在 fort.10 中单位 **dyn/cm²**（×10⁻¹⁰→GPa、×10⁻¹²→Mbar）；
  MULTI1Dvisual Config 换算已内置。
- E200/E300 因驱动强、材料热，60 ns 全程无张力振荡——该病只在
  "驱动弱到晚期冷透"时出现；同表旧算例（有 CH 烧蚀层）40 ns 未见此病，
  烧蚀层余热是保护因素。
