# 总量 EOS 用理想气体离子拆分：低温凝聚态失效（1D 双温表失真）

**日期**：2026-08-14
**状态**：已确认（AQUA 水表案例，表级 Hugoniot 对比暴露）

## 症状

总量 EOS（无电子/离子分离，如 AQUA 行星 EOS）经 `split_ieos_table.py`
拆成 1D 双温表（EleTab 电子 + 理想气体离子）后，表级 Hugoniot 反解线
vs 源数据参考线 P 偏差中位 **+33.7%**（可用段 ρ1≤2.46）。直接对拍
(ρ=1 g/cc, T=348 K)：拆分重建 P = **−1e-6 Mbar（符号反转）**，
AQUA 原始 +6e-4 Mbar；中温段（0.05–1 eV）偏差 ±12~50%。

## 根因

`split_ieos_table.py` 的拆分假设（`agent/../multi-eos-format` §5）：

```
EleTab:  P_e = P_tot − ρ·cte·T_tot   （减理想气体离子贡献）
GasIEOS: 理想气体 γ=5/3，T=ΔE/(1.5·cte)，P=ρ·ΔE/1.5
         cte = k_B/(A·m_u)
```

「理想气体离子」只在**高温等离子体（分子已解离/电离，离子可视为经典理想气体）**
成立。对**低温分子凝聚态（液相/固相水等）**完全不成立：
- 分子间氢键/范德华力主导压强，不是理想气体动能压；
- 分子转动/振动自由度使热容远超 3/2 k_B；
- 于是 EleTab「减理想离子」把凝聚态压强的负贡献全塞进电子通道，
  拆分重建的 Ptot 系统性失真，冷端甚至符号反转。

**陷阱识别**：`split_ieos_table.py` 的自洽抽查「(Pe+Pi)/Ptot」是
**数值恒等式**（EleTab 按减法定义 + 理想离子按同一 cte 加法），
在 LTE 下必然 ≈1.0000，**不验证物理正确性**。用它当作「拆分可靠」的证据
会掩盖上述失真——必须另做拆分重建 vs 源数据的**绝对值对拍**。

## 处置

- 明确分级：**2D 单温总量表准确可用**（总量直接转换，无拆分近似）；
  **1D 双温表低温段（≲1 eV）不可信，高温段（分子解离后）才逐渐可用**。
- 对总量 EOS 且无真 e/i 分离的材料（AQUA、各种行星/低温 EOS），
  迁移记录必须如实标注 1D 表的低温精度局限，不得以自洽抽查背书。

## 何时要想到它

任何「无电子/离子分离的总量 EOS」要拆 1D 双温表：
- 先看材料形态——金属/高温等离子体可用理想离子拆分；
- 分子液体/固体（水、聚合物、冰、行星冰）低温段必须警惕，理想离子拆分失真。
- FEOS 水表（WaterFEOS）无此问题：FEOS 源自带**真 e/i 分离（17 场）**，
  1D 表直接由真电子/离子通道转换，对拍 data.txt 真值 P≤1.6%。
