# 方波激光沿被输出帧分辨率抹宽——"图和设置不一致"的三个坑（2026-09-07）

**日期**：2026-09-07（CH-Au-Diamond_800J-1ns 首版波形图被用户指出
"和设置有差别"触发）。这是 laser_waveforms 管线坑的续篇，与既有记忆
"dt_aout 加密"坑同族：**输出分辨率必须与被诊断的波形特征同量级**。

## 1. 核心坑：沿宽度 vs 输出帧间隔

**症状**：data.in 明明设了 0.02 ns 软沿（ttab=0/0.02/0.98/1.0）+
pimax 能量补偿，laser_waveforms.png 上的差分曲线（ΔLASER/Δt）却显示
~0.1 ns 的缓升缓降（下降沿帧值 1.27 而非归零），被误读为"没设沿"。

**根因**：fort.10 帧间隔 dt_bout=0.1 ns >> 沿 0.02 ns。差分曲线是帧间
平均功率，任何小于帧间隔的波形特征都被抹成帧宽的台阶。

**处方**（方波/整形脉冲算例配置模板）：
- 沿取脉宽的 ~1%（1 ns 脉冲 → 0.01 ns 沿），数值上足够方；
- **dt_bout ≤ 沿宽**（0.01 ns 沿 → dt_bout=2e-11），沿在图上只剩一帧
  过渡；代价是 fort.10 增大（本例 146 帧 21 MB → 525 帧 75 MB，可接受）；
- pimax = E/(A·T_eff)，T_eff = 脉宽 − 沿宽（两沿各半：梯形积分）；
  1 ns/0.01 ns 沿 → T_eff=0.99 ns。验证：入射积分应精确还原 E/A。
- 已验证无副作用：沿 0.02→0.01 ns 重跑，能量误差 4.3e-13→4.7e-13、
  激波轨迹 25→26 km/s 不变。

## 2. 吸收曲线口径：fort.10 差分优于 fort.11 Σdepo·w

HOPG 的 plot_waveforms.py 用 fort.11 逐 step 的 Σdepo·w（depo 列 =
e%d×ρ，erg/s/cm³，×格宽 → W/cm²）。在本算例直接移植会得到荒谬吸收率
（144641 vs 159 J/cm²）：**fort.11 块数由 dt_aout 控**（本例 82 块、
0–1 ns 激光段仅 ~5 块），trapz 在欠采样段误差巨大。

**处方**：吸收/入射功率一律用 **fort.10 的 DELAS/LASER 累计能量差分**
（帧均匀、且与能量收支严格一致）；注意 DELAS/LASER 是**累计值**，
总量取终值、功率取 diff/dt。本例三口径闭合：名义解析 159154.9 /
入射 159160.0 / 吸收 159160.0 J/cm²（**wkb 口径吸收率可到 100%**：
e%laser 与 e%delas 同源累加，CH 电晕光学厚时物理合理，两条差分线重合）。

## 3. 波形解析正则：只认赋值行

data.in **头注释**里写了 "pimax = 800J/(pi*0.04^2 ...)"，正则
`pimax\s*=\s*([0-9.eE+-]+)` 会抢匹配到 800（"J/" 截断）。ttab/ptab
行尾注释也含逗号后的文本。**处方**：按行 strip().startswith(key) 取
赋值行，值段先 split('!')[0] 再解析（CH-Au-Diamond 算例的
plot_waveforms.py 是修复后的参考实现）。
