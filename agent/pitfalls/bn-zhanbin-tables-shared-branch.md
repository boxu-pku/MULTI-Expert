## 1. 换表差异的定位方法（可复用）

用户只说"旧表有错误"。定位步骤：同网格表逐值 diff **按 ρ 分段统计相对差**
（不是全表一个数）——结果：离子表逐值未变；电子表修正全部在 ρ≲3.5
（ρ<2 中位 456%、3–3.5 差 6%、**ρ>3.5 为 0%**），e0 低区平移 ≤0.05。
全表中位差（65.6%）会误导成"表大改"；分段图立即看清修正本质=膨胀/张力区。

**推论（对验收的含义）**：冲击 Hugoniot 采样 ρ>3.5 → 换表对冲击验证
零影响（hBN @2.04 vs ZhangHuan 旧 +2.69% → 新 +3.17%，同级）；但
**低密度态（烧蚀羽流、膨胀区、稀疏波）物理已变**——旧产物不可再对表，
凡涉及 ρ<3.5 的旧算例结论需重审。

## 2. 两相共用高压缩分支（引用必读）

cbn{ele,ion} 与 hbn{ele,ion}：**离子表完全相同**；电子表 **ρ>3.5 完全
相同**、差异只在 ρ<3.5 冷区（cBN/hBN 之别全在初始冷态实现）。因此：

- cBNHub @3.45 自洽 Hugoniot 与旧表（实为 hBN 数据）@3.45 **几乎重合**
  （<0.1%）——不要因为"线和换表前一样"怀疑迁移搞错；
- 高压缩下两相 EOS 趋同是物理合理的建模选择（同成分熔化/等离子体态），
  但与 FEOS_dm（两相全域不同）口径不同，跨源对比时注意；
- 两表套用同一 rho0 族分析时，@2.04 与 @3.45 线的差异**只来自 RH 锚点**
  （E0/P0/V0），不是波后物态不同。
