# 温稠密-only DFT 表（无冷曲线）不能在 MULTI 中模拟

**日期**：2026-08-14
**状态**：已确认机制（C8H8_wk 为例）

## 症状

WeiKang 刘兴 A3/A2 类 DFT 表转换入库后，1D 算例在第 ~6 步崩溃：
`ERROR in subroutine tridia: singular matrix found`。
初态放进数据域内（r0=2.1, te0=0.6 eV）也同样崩。

## 根因链

1. **源数据无冷区**：刘兴 A3（C8H8）ρ=1.05 行最低 T=58 eV，其余行（≥2.1）
   最低 0.58 eV——没有任何近环境（0.03 eV 级）数据，没有真冷曲线；
2. **IEOS 格式强制冷曲线**：MULTI 要求 e0(ρ)+de（de≥0），转换只能拿
   "每行最低 T 点"充冷曲线 → ρ=1.05 行的"冷"态实为 58 eV 热态，
   冷压高达 31 Mbar（物理上应≈0）——**冷曲线是伪造的**；
3. **伪造行与真实行之间 P(ρ) 倒挂**：de≈0.02 层 P(1.05)=27.5 Mbar >
   P(2.1)=0.53 Mbar → **∂P/∂ρ<0，声速平方为负** → 双曲方程椭圆化 →
   隐式 hydro 三对角矩阵失去对角优势 → `tridia` 奇异；
4. 初态即使放在真实数据区，自由面一扩张就插进伪造区，同样崩（实测）。

## 证据图

`validation_cases/C8H8_wk/C8H8_wk_unusable_evidence.png`（三联）：
(a) 源数据 (ρ,T) 覆盖 vs 模拟需求域（常态起点在数据下方 1.5 个量级之外，
0.58 eV 以下无数据）；(b) 各行最低 T 点的 P(ρ)——1.05 行底为 58 eV/28.5 Mbar，
2.1 行底为 0.58 eV/0.49 Mbar，P 随 ρ 增大而跌 → ∂P/∂ρ<0；
(c) 转换表 ∂P/∂ρ 符号图——负值 73 单元全在 ρ∈[1.05,2.1]、de≤10.6
（T≤85 eV，模拟必经区）。

## 判定规则

转换任何 DFT/FPMD 表前先看：**每个密度行的最低 T 是否到近环境**、
**密度网格是否覆盖常态 ρ0**。两者缺一就是温稠密-only 表——可作
**高温区逐点对照数据**（如 C8H8 vs CH 表的 164 点对照），不能直接跑模拟。
要跑模拟必须先补低温/低密数据并重建合理冷曲线（blending），
而按迁移规范"不伪造数据"，这类表判 **1D 不可用、保留作参考**。

## 正面例

CH2_wk（ρ≥1.91、T≥0.44 eV 全是真实数据行）：Check 算例从 r0=1.91
初始化（在数据域内），通过验收（5.5e-12）——因为它没有伪造行。
