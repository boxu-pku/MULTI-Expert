# 衰减激波轨迹回推 t0 系统性偏早（double_shock hBN 侧）

**日期**: 2026-09-22　**战役**: double_shock_hbnfeos　**来源**: 用户指正（49188 BN 侧 t0 有误）

## 现象

B 侧（hBN 样品）t0 用"LC 波前轨迹全程线性拟合回推至样品入口"判据，7 个定版算例
的 t0 全部比真实激波到达偏早 0.04–0.07 ns（49188: 回推 1.552 vs 首格密度跳变
1.642），使 Us（=厚度/(t2−t0)）系统性偏慢约 0.5–1%。

## 根因

激光驱动的激波在样品内**沿途衰减**（波后压力降→波速降）。全程单一线性拟合的
斜率被早期快速段拉大，回推到入口时刻早于真实到达。轨迹本身并不需要"波动"才会
错——即使跟踪完全干净（如 49188，LC 残差 σ=0.12 µm、无回跳），线性回推依旧偏早。

## 正确判据（用户口授 2026-09-22）

t0 = **近 base 的第一个样品格**在 **LC 密度热图**上水平剖面的**首个密度跳变沿**。

为何用密度而非 PT：
- 解冻/松弛漂移：波前密度**缓降**（49188 首格 2.02→1.75 g/cc），不会触发正跳变；
- 辐射预热脚：PT 缓升（0.07→0.12 Mbar）但密度不升，被天然滤除；
- 真实激波是阶跃：密度一步 1.75→3.05（步幅 0.45–1.0×ρ₀），阈值取步幅 ≥0.1×ρ₀
  即可无歧义命中（7/7 算例首格只有一个早期正跳变）。

## 教训

- 衰减波不能用全程线性回推定到达时刻；要在固定拉格朗日格上做局部跳变检测。
- 判据尽量落在"观测量是阶跃、干扰是缓变"的变量上（此处是密度，不是 PT）。
