# 混合单位平方和：km/s 与 m/s 直接相加（2026-09-10，visar R2.b/S4 两案）

## 现象

计算弹性纵波速 `c_L = sqrt(c0^2 + (4G/3)/rho0)` 时，`c0` 以 km/s、弹性项
以 SI（m/s）² 直接相加：

- `r2_overlay.py`：`cL = np.sqrt(C0**2 + (4*G*1e9/3)/(RHO0*1e3))/1e3`
  —— c0²=93.9 (km/s)² 被 ~1e8 (m/s)² 淹没，**等于把体声速整个丢了**。
  错误结果 c_L(G=400)=12.33 km/s，正确值 15.68 km/s；标定带整体从
  G≈400–500 偏移到 G≈190。
- `analyze_target.py` 初版又原样复刻了同一 bug（cL_th=7.55）。

同一会话内"发现-修复-复刻"说明该写法极易复发。

## 规则

任何 `sqrt(a^2 + b^2)` 前先把两项**显式换到同一单位**（推荐全 SI：
`(c0*1e3)**2 + term_si`，最后 `/1e3` 回 km/s）。跨脚本移植公式时先手算
一个已知点验证。
