# 双温交换振荡（Te/Ti sloshing）致波后密度振荡

**日期**：2026-08-14
**状态**：已确认机制并修复（算例侧限幅）

## 症状

FEOS 表（QuartzFEOS/SilicaFEOS，2026-08-14 改名前互换）的 Hugoniot 算例在 trad≥100 eV（P≳4 Mbar）时，
波后密度出现**网格尺度持续振荡**（±25%，不衰减），平台取样落在压力尖峰上，
提取的 Hugoniot 点系统性偏理论线 ~15%。Multi_BACK 表同驱动强度下干净。

## 诊断（关键证据）

振荡单元上 **Ti 被打到 0.00 eV 而 Te 高达 7-9 eV**——电子-离子能量在相邻单元间
来回倒换不收敛（双温交换 sloshing）。根因是 FEOS TF 电子 EOS 的 Cv 结构使交换
时间尺度在该 (ρ,T) 区远小于流体时间步，而算例的时间步控制里
`dttevar/dttivar=1e12`（=不限幅），交换项一步就能把 Ti 打负（被钳到 0）。

## 修复

data.in 加温度变化限幅（m150304 时间步控制 `var=max(...,varte/dttevar,varti/dttivar)`）：

```
dttevar = 0.5,
dttivar = 0.5,
```

效果立竿见影：波后 Ti 不再归零、Te=Ti 平衡、密度平台平滑，
T100 提取点 12/12 回到 RH 残差 ≤1% 并贴上 FEOS 线（0.2 同样有效但更慢）。
**`make_hugoniot_cases.py` 模板已默认带 0.5**。
降 `fei`（交换率因子）0.2 实测**无效**——2026-08-20 复现核实补充：Hugoniot 算例
`model=0`（经典等离子体）路径下 `collfreq` 的 `case(0)` 分支根本不使用 fei，
改它输出**逐位不变**（空开关）；即"降交换率"这条路在该配置下从未真正试验过，
真正验证"时间步对症"的是限幅变体本身。

**代价权衡**：限幅在光滑区不增加步数，但在多群辐射前驱陡峭区会持续约束 dt
（Al T100：12 s → 381 s @0.5）。Al/Silica/Quartz 等 Multi_BACK 表无限幅时本就
干净，故这些算例保留 1e12 默认值；**FEOS 表或任何出现 Ti=0 振荡的算例用 0.5**。
若新材料验证算例因限幅过慢且剖面确认无振荡，可放宽回 1e12。

## 何时要想到它

任何**双温表**（eeos+ieos）算例出现波后/松弛区网格尺度振荡、Ti 贴 0、
Te/Ti 剧烈分层——先查 dttevar/dttivar 是否被设成了 1e12 这类"等于没有"的值。
与 EOS 表本身质量无关时也可见（如强驱动下交换率天然很大）。
