## 1. 问题本质与本项目实测证据

流体程序无固体本构：冷物质（常温 Al/Quartz）服从流体方程，任何冷压差都会驱动
非物理流动。真实固体靠弹性行为承受远小于屈服强度的压差。

Decay_wave base（修正几何版）实测，激波 5.25 ns 才入 Quartz，但此前已发生：

| 伪影 | 实测值 | 机制 |
|---|---|---|
| 初态冷压失配 | QuartzFEOS(2.65, 0.1 eV)=+0.051 Mbar，AlFEOS(2.70, 0.1 eV)=+0.004 Mbar，界面 ΔP≈0.047 Mbar | 两种 FEOS 冷曲线在标称密度处都不严格过零 |
| 接触带预扰动（t=4 ns） | 石英侧稀疏到 2.27 g/cc、铝侧压到 2.85 g/cc | ΔP 驱动的声波调整（真实固体弹性吸收） |
| 左自由表面"蒸发"（t=4 ns） | x<10 μm 出现 ρ~0.015 g/cc 低密度羽（表面 Te 仅 0.32 eV） | 0.05 Mbar 冷压把表面推入真空——手册原话"材料向真空中扩散（不是预热！）" |

后果：激波前方石英已非完好 2.65 固体，入界时刻与穿出段 Us 被系统性污染；
对飞片/间隙类算例（Multi_BACK 的 Gap 系列）误差更大。

## 2. Multi_BACK 的 Quiet Start（调研结论）

- **机制**（手册 slide 75 原文）："设置开关温度，初始时刻所有网格的流体力学冻结；
  如果温度升高到某个阈值，网格的流体力学开关打开。"——**逐单元温度门控的
  流体冻结**，通用做法源自 Hyades/Bucky1D。
- **实践参数**：全局 `QuietStartSwitchTemperature=0.1~0.2 eV`；逐层
  `TiQuietStart(i)=1000 eV`（核心源码不在本机，逐层参数的确切角色不可考，
  实际生效的是全局开关温度；实装时我们用单一参数即可）。
- **已废弃的替代路线**（slide 76）："忽略初始压强差"（直接抹冷压）因人为缩小
  真空界面压差、**压低飞片速度**被废弃——所以选"冻结运动"，不选"改压力"。
- **配套陷阱**（slide 79）：冻结期间密度无变化会触发 "no variations" 报错，
  必须开 Te/Ti 变率步长控制。**我们当前 dttevar/dttivar=0.5 已满足**。

## 3. m150304.f95 现状与改造落点

- 1D/2D 均无任何 quiet/freeze 机制（grep 证实）。
- 唯一刚性约束是边界：`ileft/iright=1` 把边界界面方程替换为 v=0 的三对角行
  （`m150304.f95:L1055-L1063`）——**这正是可推广到内部界面的现成模式**。
- 动量方程为鲁棒隐式三对角（`L925-L1075`）：装配 a/b → `tridia` 解速度增量 →
  `s1%v += b`。冻结界面只需在装配后做行替换，结构不变。

## 4. 方案对比与推荐

### 方案 A：初态预条件化（零代码，立即可用）
逐层对 te0 二分求解 P(ρ0, te0)=0（钳制在表 T 下限内）+ 冷侧自由边界 ileft=1。
- 优点：不动源码，今天就能跑。
- 局限：QuartzFEOS 电子表 tmin=0.28 eV，P=0 未必可达（只能把残余压差从
  0.05 降到 ~0.01 Mbar 量级）；解冻后材料仍无强度；每对材料都要重算。
- 定位：**作为 interim 验证问题量级，不是终态**。

### 方案 B（推荐）：移植温度门控 Quiet Start 到 m150304.f95（约 60 行）
1. 新参数（&parameters 块）：`iquiet`（0/1，默认 0 保持向后兼容）、
   `tquiet`（eV，默认 0.2，与 Multi_BACK 实践一致）。
2. 状态：`thawed(n)` 逻辑数组（随 state 分配），**闩锁式**——一旦
   `Te>tquiet 或 Ti>tquiet` 永久解冻，避免稀疏降温期反复冻结。
3. hydro 子程序装配三对角后：界面 j 两侧单元均未解冻 →
   `b(j)=0; a(2,j)=1; a(1,j+1)=0; a(3,j-1)=0`（与 ileft/iright 同型行替换）；
   边界界面 1/n+1 按同规则处理（自然涵盖 rigid BC 语义）。
4. 输出：print 参数、初始冻结界面数；output 记录首解冻时刻。
5. **判据的物理合理性**：伪影驱动（~0.05 Mbar）只能维持 Te~0.1 eV < 0.2 → 永冻；
   真实辐射预热/激波把 Te/Ti 推到 eV 量级 ≫ 0.2 → 激波到达即解冻，传播几乎
   不受影响（门控只延迟一个单元的加热时间）。
6. 已知代价：冻结界面不做功，解冻瞬间能量收支有小扰动；当前 error~1e-13，
   余量充足，验收沿用 <1e-4 门禁。

### 方案 C（远期立档）：弹塑性本构
偏应力张量+屈服强度是物理完备解，但需重写 1D/2D 两套应力与能量方程；
对 ≥10 Mbar 驱动（强度 ~GPa=0.01 Mbar 量级）增益有限。不建议现在做。

## 5. 2D 侧（r94）路线

同语义二期移植到 M20_Step/hydro2（逐单元冻结网格运动）；2D 涉及 ALE/网格
重构耦合，冻结逻辑复杂度高，**建议 1D 验证算法正确后再动 2D**。

## 6. 实装后的验证计划

1. base 重跑：t<5 ns 激波前方石英应严格保持 ρ=2.65、Al 保持 2.70
   （左表面无 0.015 羽、接触带无 2.27/2.85 预扰动）。
2. 激波入界时刻/Us 历史对比（预期小幅偏移——前方密度场更真实）。
3. error 与 normal termination 检查（沿验证规范 §B2）。
4. 回归测试：iquiet=0 应逐位复现当前 base。

## 7. 结论

**推荐方案 B**：一次改造、全系列受益、与 Multi_BACK/Hyades/Bucky1D 社区实践
一致；方案 A 可先跑一轮量化问题基线；方案 C 立档不动。
